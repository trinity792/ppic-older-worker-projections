# Project Memory

This is the concise index of durable project knowledge. Keep it short. Put
detailed decisions and discoveries in dated files under `agents/memories/` and
link them here.

## Durable facts

- This repository will replace the preexisting website in `v0/`.
- The product has one focused role: explore historical and projected outcomes
  for older workers in California.
- `v0/` is the read-only behavioral and data reference for the migration and must never be modified.
- The project should share the design language and principles of the sibling repository `../web-data-visualization`, but with substantially less architecture and interface surface.
- The web-data-visualization project is read-only and must never be modified.
- This directory is already a Git repository.

## Established decisions

- Agent guidance lives at the root and under `agents/`.
- Former "convention" guidance is represented as task skills in `agents/skills/`.
- Lightweight Markdown guidance is available at `agents/skills/markdown.md`; prose paragraphs and list items should not be hard-wrapped across unnecessary source lines.
- General Python guidance is available at `agents/skills/python.md` if Python becomes part of the project.
- Long-lived context uses this index plus focused records in
  `agents/memories/`.
- The root migration will use Vite, React, TypeScript, npm, granular visx/D3 primitives rendered as React SVG, and static Vercel hosting. See [`agents/memories/2026-09-18-migration-stack.md`](memories/2026-09-18-migration-stack.md).
- The versioned data layout uses an unchanged export under `public/data/raw/` and a deterministic serving file under `public/data/cleaned/`, generated and checked by dependency-free Python scripts. See [`agents/memories/2026-09-18-data-layout.md`](memories/2026-09-18-data-layout.md).
- Vitest and React Testing Library cover unit/component tests, Playwright covers browser checks, and Python's standard-library `unittest` covers cleaning scripts.
- The migrated race/ethnicity control includes Pacific Islander as an approved difference from `v0/`. It maps the existing `pacis` field and remains subject to whole-comparison suppression; the full-period selection is suppressed because its 2006 and 2007 populations are below 20,000.
- Workstream 1 (freeze the legacy contract) is complete. Ten browser-captured parity fixtures live in `tests/fixtures/parity/`, generated by a reusable Playwright script against the real, unmodified `v0/` app. See [`agents/memories/2026-09-18-legacy-parity-fixtures.md`](memories/2026-09-18-legacy-parity-fixtures.md) for the method and for discoveries workstreams 4 and 8 need: a deeper CSV raw-mode mismatch than previously recorded, `v0`'s download button never disabling itself, and the "no rows match" branch being unreachable against the production dataset.
- Workstreams 3-9 (parser, calculation pipeline, comparison state/controls, design tokens, chart, table/CSV export, accessibility pass) are implemented and checked (`npm run lint`, `npm run typecheck`, `npm test`, `npm run test:e2e`, `npm run test:python` all pass). See [`agents/memories/2026-09-18-implementation-workstreams.md`](memories/2026-09-18-implementation-workstreams.md) for what was built and non-obvious discoveries (a chart-label contrast constraint, a test-tooling `tsconfig` split, and an RTL cleanup gap).
- The migrated CSV download uses a new contract, not the legacy rate-only one: it exports the displayed value plus explicit `status`/`unit` columns and omits suppressed comparisons entirely. User-approved; do not revert without asking again.
- Typography, buttons, the view toggle, controls, and the chart's colors/font were aligned to `../web-data-visualization`'s actual UI-kit specimens and chart defaults (not `v0/`'s look). See [`agents/memories/2026-09-18-design-alignment.md`](memories/2026-09-18-design-alignment.md) for exact source locations and two intentional accessibility deviations from the reference's own code (eyebrow/outline-button text color, one chart series color).
