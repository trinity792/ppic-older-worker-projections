# Detailed Project Memories

Store durable, dated decision and discovery records here using
`YYYY-MM-DD-short-topic.md`. Summarize and link each active record from `../memory.md`.

Do not use this folder for session logs, speculative notes, task checklists, or information that can be recovered easily from the code.
